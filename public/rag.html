Recommended flow
  1. Review the status on the left. If the runtime dimension and collection size differ, do not switch models in place.
  2. Create a new target collection for the new embedding model, for example `agentx_embeddings_qwen3`.
  3. Run reindexing into that new collection.
  4. Validate search quality against the new collection.
  5. Only then update `EMBEDDING_MODEL`, `EMBEDDING_DIMENSION`, and `QDRANT_COLLECTION` together and restart AgentX.

How this works

Uploads from this UI send the file text to /api/rag/ingest and are stored in the vector store (Qdrant payload contains the text chunks). Folder scanning is typically done by n8n; it should (1) POST each file to /api/rag/ingest and (2) POST a manifest snapshot to /api/rag/manifests. The Deletion Preview compares RAG docs for a source against the latest stored manifest for source+root.
