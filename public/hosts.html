Install the AgentX Host Agent on each machine you want to monitor.
It collects CPU, RAM, GPU, disk & network metrics and reports every 30 seconds.

Quick Test

Run the agent once to verify connectivity:

  1. On the target host, clone or copy the tools/host-agent/ folder
  2. Install the dependency:
cd tools/host-agent && npm install
  1. Run the agent (replace the URL if needed):
AGENTX_SERVER= node agent.js

Requires Node.js 18+. The host should appear above within seconds.

Linux — Persistent Service

Install as a systemd service that starts on boot:

sudo bash install.sh

Run from inside the tools/host-agent/ directory.
Installs to /opt/agentx-host-agent and enables the agentx-host-agent systemd unit.

  • Status: systemctl status agentx-host-agent
  • Logs: journalctl -u agentx-host-agent -f
  • Stop: systemctl stop agentx-host-agent

Windows — Scheduled Task

Install as a scheduled task that runs at startup:

powershell -ExecutionPolicy Bypass -File install.ps1 -Server ""

Run as Administrator from the tools\host-agent\ directory.
Installs to C:\AgentX-Host-Agent.

  • Status: Get-ScheduledTask AgentXHostAgent
  • Stop: Stop-ScheduledTask AgentXHostAgent

Configuration

Environment variables accepted by the agent:

  • AGENTX_SERVER — server URL (required)
  • AGENT_TOKEN — auth token, must match server's HOST_AGENT_TOKEN
  • AGENT_INTERVAL_MS — report interval, default 30 000 ms
  • AGENT_HOST_ID — custom host ID, default auto-generated from hostname

The agent has a single dependency (systeminformation) and works on Linux, Windows & macOS.

Already have Ollama hosts? They appear on the Host Test page. Install the agent on those machines to add live system monitoring.
