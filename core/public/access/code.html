Code parental

Ce code est défini dans la configuration de l’instance (AGENTX_PARENTAL_CODE). Il se change là, sur l’ordinateur qui héberge AgentX.

Après le changement, les autres appareils déverrouillés doivent entrer le nouveau code. Un code fait uniquement de chiffres s’ouvre dès le dernier chiffre tapé.
