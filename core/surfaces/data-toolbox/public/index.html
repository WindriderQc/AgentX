No filesystem actions. This page can send nine kinds of change to Data.

Survivor choices and accept/reject decisions are saved to Data as a record of intent for a later, separately confirmed cleanup; a local draft takes over when Data cannot be reached. Preview, apply, move and delete endpoints are not exposed here.

This page sends nine kinds of change to Data:

  1. a network device's record (name, known flag, type, location, notes);
  2. a network scan request for the active collector;
  3. an MQTT message published by hand from the MQTT tab, which reaches the devices on the broker;
  4. a storage scan request from the Storage tab, which only reads the disks and refreshes the index;
  5. the duplicate-review decisions of the Janitor tab (saved, imported from this browser's draft, or removed), which delete no file;
  6. the generation of a report from the Storage tab;
  7. the deletion of a report from the Storage tab;
  8. an IoT device’s display name, location and notes;
  9. an explicit GPIO ON/OFF or reboot command from the IoT tab.

A report is a file in Data's own report store, never on the scanned disks.
