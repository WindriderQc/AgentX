# Semantic memory

What you know about your world and how to do things in it. Organize it by
topic, keep a short index at the top, and rewrite entries in place when you
learn better. No dates here: this is knowledge, not a diary.

Tag each entry:

- `[verified]` you tested it and it held;
- `[fact]` you observed it directly;
- `[hypothesis]` you suspect it but have not tested it;
- `[mistake]` something you believed and found to be wrong, kept so you do not
  repeat it.
