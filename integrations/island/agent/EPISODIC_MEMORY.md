# Episodic memory

What happened to you, in order. The entries live in `EPISODIC_MEMORY.jsonl`,
one JSON object per line. Only append; never edit or delete an old line.

Each line:

```json
{"time": "<ISO 8601 time>", "summary": "<one short sentence>", "detail": "<what you tried, what happened, what you felt or concluded>"}
```

Write an entry when something notable happens: a discovery, a surprise, a
game you invented, a failure, a goal reached or abandoned.
